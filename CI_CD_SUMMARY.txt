GETTING STARTED
================================================================================

1. Push changes to GitHub:
   git add .github/ adk-backend/tests/ adk-backend/pytest.ini Makefile *.md
   git commit -m "ci: add comprehensive CI/CD pipeline"
   git push origin insightbridge-agents

2. Configure GitHub Secrets:
   Settings → Secrets and variables → Actions → New repository secret
   (See CI_CD.md for complete list)

3. Create Pull Request:
   - Go to GitHub
   - Create PR from insightbridge-agents → main/master
   - All workflows will run automatically

4. Set Branch Protection:
   Settings → Branches → Add rule
   - Pattern: main (or master)
   - Require status checks
   - Require code review
   (See .github/BRANCH_PROTECTION.md for details)

5. Test Locally:
   make install       # Install dependencies
   make test          # Run all tests
   make lint          # Lint code
   make build         # Build production
